# Profile System

## Recruiter narrative

**Business Intelligence → Analytics Engineering → AI Solutions → Applied AI**

The profile intentionally avoids unsupported proficiency percentages and inflated claims. Projects are the proof layer; the profile is the navigation layer.

## Six-item pin strategy

1. `enterprise-bi-copilot`
2. `ai-data-quality-agent`
3. `executive-reporting-automation`
4. `portfolio`
5. `learning-log`
6. `analytics` / open-source work once a genuinely strong contribution exists

## Trust rules

- Do not backdate commits.
- Do not claim deployment before a deployment exists.
- Do not call a prototype production-ready.
- Use synthetic data in public examples.
- Keep project status aligned with actual implementation.
